# Nextflow to Galaxy reference data

## Classification

`none`: исходный workflow не использует внешние справочные данные, индексы, геномы или базы данных.

## Source evidence

`summary-nextflow.json` содержит пустые `reference_assets` и `reference_rebuilds`. Параметр `input` указывает на обычный исходный текстовый файл `${projectDir}/data/words.txt`; его содержимое обрабатывается двумя процессами. Параметр `outdir` задает каталог публикации результатов.

## Galaxy mapping

Не требуются справочные входы Galaxy, data tables, dbkey, data managers, загрузка индексов или перестроение отсутствующих справочников. Обычный текстовый вход и два результата должны быть описаны на следующем этапе проектирования интерфейса.

## Requiredness and rebuilds

Отсутствуют справочные активы, поэтому для них не задаются requiredness, fallback или rebuild. Подмена обычного текстового входа справочным файлом была бы ошибочной классификацией.

## Open questions

Для справочных данных открытых вопросов нет. `outdir` относится к исполнению и публикации файлов; его отображение в Galaxy решает этап интерфейса.

## Feedback

no feedback: примененные заметки полностью покрыли случай отсутствия справочных данных.
