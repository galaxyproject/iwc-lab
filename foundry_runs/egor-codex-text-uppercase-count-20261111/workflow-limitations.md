# Границы результата

Сохранены 2/2 исходных вычислительных процесса, их последовательность и 2/2 опубликованных файла. Три входа проверены реальными запусками Nextflow и Galaxy, шесть выходов совпали побайтово. Это учебный текстовый DSL2 workflow пользователя, не конверсия nf-core и не биологический benchmark.

`surrendered`: исходный параметр `params.outdir` не доступен как скалярный вход Galaxy. В Nextflow он задает каталог публикации; в Galaxy эту функцию выполняют история и два публичных dataset. Выбор пути на файловой системе сервера не переносился. Причина и исходная конструкция сохранены в `open-requirements.ledger.yml`, `drop-outdir-publication-interface`. Вычислительные шаги и результаты из-за этого не удалены.

Многофайловые glob-входы, CRLF, произвольные бинарные байты и большие входы не проверены. Исходник не закрепляет версии tr/awk; версия Galaxy взята из штатной установки Planemo без `--galaxy_branch`, точный Git commit загруженного tarball неизвестен. Точный ID модели агента и стоимость сессии средой не предоставлены.

Foundry-парсер потребовал ручной проверки и дополнения сводки. Сырой CLI JSON, исправления и пять наблюдений сохранены. Успешный runtime этого небольшого workflow не означает, что автоматический перевод всех источников работает без вмешательства.
